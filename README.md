# Cerca — Servicios útiles

Aplicación web progresiva (PWA) en español, pensada para funcionar en teléfonos Android.

## Incluye
- Números de emergencia de Perú con acceso directo a llamada.
- Directorio personal para guardar servicios y contactos.
- Búsqueda y filtros por categoría.
- Edición y eliminación de contactos.
- Accesos a mapas y enlaces web.
- Datos guardados localmente en el dispositivo.
- Caché básica para abrir la aplicación sin conexión después de la primera visita.

## Publicar con GitHub Pages
1. Crea un repositorio público llamado `cerca-servicios`.
2. Sube el contenido de esta carpeta (no la carpeta ZIP).
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, luego **Save**.
6. Espera a que GitHub muestre el enlace publicado.

## Instalar en Android
1. Abre el enlace publicado con Chrome.
2. Espera a que cargue y usa el menú ⋮.
3. Selecciona **Instalar aplicación** o **Agregar a pantalla principal**.

## Abrir en Acode
Abre la carpeta del proyecto en Acode y edita `index.html`, `styles.css` o `app.js`.
Para probar la instalación PWA y el modo sin conexión, publica primero en HTTPS mediante GitHub Pages.

## Importante
- El directorio personal se guarda en el almacenamiento del navegador de cada dispositivo. No se sincroniza entre celulares.
- Los números de emergencia pueden cambiar o tener cobertura diferente según la zona. Verifica la disponibilidad local.
- SAMU 106 brinda atención en las regiones indicadas por el portal oficial del Estado.
- La aplicación no reemplaza los servicios oficiales ni garantiza respuesta de emergencia.
